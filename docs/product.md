# EVE industry planner

Plan manufacturing builds and reactions from selected blueprints/formulas, called roots in this flow. Allows adjusting build configurations for the build tree. Outputs material shopping lists, production time estimates, and job fees based on the exact configuration provided.

Users organize builds into plans, choose runs and print counts for roots (only prints for children, runs are calculated), adjust blueprint ME/TE efficiencies, choose components to buy or build, and assign structure profiles. Calculations use published EVE recipes and stable type IDs. Allows ME/TE and structure profile overrides for indivdual child prints to simulate a variety of setups.

- [BOM](features/bom.md): settings, dependencies, quantities, time, and shopping lists.
- [Structures](features/structures.md): profiles and bonuses.
- [Job fees](features/job-fees.md): production installation costs.
